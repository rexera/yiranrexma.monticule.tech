# 设计刷新 · 2026-10 实施记录

> 修订：先前版本曾建议衬线标题 + 圆角卡片，已被否决。本版记录**实际采纳**的方向与已落地内容。

## 确认过的方向

| 项 | 决定 |
|---|---|
| Hero | 保持原布局，不做胶囊按钮，也不加背景特效 |
| 名字 / 照片 | 不放大，不招摇；照片保持锐利矩形 |
| 圆角 | 全站零圆角（含图片、代码块、行内代码） |
| 字体 | 不用系统字体、不用衬线；年轻、铺开阅读无压力 → **Instrument Sans Variable**（自托管） |
| 颜色 | 背景色与主题色保持不变；只从 Monticule VI 的**色板**取色，不采用其字体规范 |
| 列表页 | Blog / Work 统一为同一套行结构 |
| 长文 | MDX 正文做视觉层面的滚动懒加载 |

## 已落地

### 字体
- 新增 `@fontsource-variable/instrument-sans`，Latin 走自托管 Instrument Sans；中文回退 PingFang SC。
- Maple Mono 改为自托管 `public/fonts/`（latin 可变 + CN 静态子集）。
- 两处字体机制注意点：
  1. **中文子集必须用独立 family 名**（`Maple Mono CN`）。同一 family 下多张 face 并存时，Chrome 不会为缺字在同一 family 内换脸，中文会静默回落到系统字体。
  2. **静态字体不能声明字重区间**（`font-weight: 400 500` 会被忽略），CN 子集按 400/500/600/700 逐条声明。
  3. latin face 必须写 `unicode-range`，否则它声称覆盖所有字符，CN 子集永远不会被请求。

### 色彩
- 新增 VI 色板到 Tailwind：`vi-sprout / vi-oliveLight / vi-olive / vi-sage / vi-wordmark / vi-deep / vi-cream / vi-ground / vi-ink`，仅作装饰色（圆点、雾霾、标记）。
- 新增 `--brand-text`（亮色 `#5E6C53`，5.29:1；暗色 `#C1C989`）用于小号强调文字，修掉原来橄榄绿 `#81986a` 在纸面仅 2.99:1 的问题。
- 文章图注 `#77815f` → `#65745a`（3.89:1 → 4.7:1）。
- 背景色、主题橄榄色未改。

### Hero
- 首屏不做任何背景特效：纸面保持干净，只有排版、三行 lead、关键词与锐利矩形肖像。

### 首页结构
- 首屏不放任何超链接：姓名、副标题、三行 lead、三个关键词，全部为纯文本。
- 姓名上方不再有 eyebrow（不构成三明治）。
- 副标题按「母语名 + 地点分段」拆成多个 span（"中国·北京" → 中国 / 北京），每段之间 12px 间距，CJK 中点不再挤在一起。
- 删除原「01 当前重心」区块；成果 / 动态 / 写作顺次变为 01 / 02 / 03。

### 文章排版
- 中文破折号「——」中间插入 word joiner（U+2060），消除 UAX #14 给 em dash 的断行机会；代码与公式不受影响。
- 列表页（Blog）取消「最新文章」的放大层级，全部行同一字号、同一结构。
- 筛选条只保留下边线（`border-t`），与列表自身的上边线不再相邻重复。

### 列表页统一
- 两页共用行结构：108px mono 元信息列 + 内容列，发丝线由列表容器统管。
- 类型标记：research / 会议 / 期刊 / 专利 = 橄榄点；note / 预印本 = 地衣灰绿点。颜色只做标记，文字仍用 `muted` 保 AA。
- hover：整行极淡底色 + 标题转为 `brand-text`，无位移、无阴影。
- 筛选条激活态改用 `brand-text`。

### 长文懒加载（`components/article-reveal.tsx`）
- 扫描 `.mdx-article` 直接子块，仅给首屏以下的块打 `data-reveal`，交错延迟上限 120ms。
- 已有的 CSS 机制负责隐藏/显现，因此无 JS 与 reduced-motion 下正文完整可见。
- 挂载于 `ArticleShell`（博客 / 论文详情）与 Story 页。

### 其他细节
- 文章图、代码块、行内代码、kbd 去圆角。
- Callout 标题、TOC 激活项改用 `brand-text`。
